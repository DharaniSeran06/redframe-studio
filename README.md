## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/redframe-studio.git
```

Go to the project folder:

```bash
cd redframe-studio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
